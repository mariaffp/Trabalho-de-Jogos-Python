Trabalho 2:
- Jogo simples desenvolvido em Python com Pygame utilizando uma grade e alguns requisitos criados pelo professor(uso de teclado, mouse, movimentação...)

## Como jogar

- Use as setas do teclado para movimentar o pato;
- Colete os pontinhos pelo mapa;
- Clique em um espaço livre ou no próprio pato para ativar o poderzinho QUACK;
- Evite o pato inimigo que te persegue;
- Quando o QUACK estiver ativo, o inimigo não diminui seus pontos, aumenta(mas eu poderia tirar isso para dificultar).

## Objetivo

Coletar pontinhos e sobreviver ao pato inimigo diminuindo seus pontos e te perseguindo. 

## Como executar

Dentro da pasta `Trab2`, execute:
python main.py
